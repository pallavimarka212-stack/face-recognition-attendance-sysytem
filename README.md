\# Face Recognition Attendance System



A Python-based attendance management system that uses \*\*face recognition\*\* through a webcam to identify registered users and record their attendance automatically.



\## 📌 Project Overview



This project is designed to reduce manual attendance work by using face recognition technology. The system captures a person's face through a webcam, identifies the registered person, and records the attendance with the date and time.



\## ✨ Features



\* Face detection and recognition

\* Webcam-based attendance

\* Automatic attendance recording

\* Date and time tracking

\* Simple web interface

\* Helps reduce manual attendance work



\## 🛠️ Technologies Used



\* Python

\* OpenCV

\* DeepFace

\* Flask

\* HTML

\* CSS

\## ⚙️ How It Works



1\. The application starts the webcam.

2\. The system captures the person's face.

3\. DeepFace is used for face recognition.

4\. The recognized person is identified.

5\. Attendance is recorded with the current date and time.
